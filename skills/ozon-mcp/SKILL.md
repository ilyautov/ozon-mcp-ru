# Ozon Seller через MCP

Ставит сервер `ozon-mcp-ru`: 441 метод официального API
(чтение 190, запись 240, необратимое 11). Каталог методов лежит в YAML и
исполняется сервером, поэтому агент получает несколько универсальных
инструментов, а не по отдельной функции на каждый метод.

## Установка

Пакет на PyPI, поэтому строка одна:

```bash
uvx ozon-mcp-ru
```

Если нужна ветка `main`, а не релиз:

```bash
uvx --from git+https://github.com/ilyautov/ozon-mcp-ru ozon-mcp-ru
```

Конфигурация клиента (Claude Desktop, Cursor, Claude Code):

```json
{
  "mcpServers": {
    "ozon": {
      "command": "uvx",
      "args": ["ozon-mcp-ru"],
      "env": {
        "OZON_CLIENT_ID": "<значение>",
        "OZON_API_KEY": "<значение>"
      }
    }
  }
}
```

## Где взять ключи

- `OZON_CLIENT_ID`: Client-Id из кабинета seller.ozon.ru, Настройки → API-ключи.
- `OZON_API_KEY`: Api-Key из той же пары. Оба уходят в одноимённые заголовки.

Второй путь, без переменных окружения: поднять сервер и вызвать
`ozon_add_cabinet`. Ключи лягут в `~/.marketplace-mcp/cabinets.json`
с правами 600 и с машины не уходят. Так же подключается второй магазин.

## Что спрашивать у сервера

- `ozon_search_methods("остатки по складам")`: поиск метода словами.
- `ozon_describe_method(...)`: параметры, пагинация, класс доступа.
- `ozon_call_method(...)`: вызов. Чтение идёт сразу, запись просит
  подтверждения, необратимое просит дважды.
- `ozon_check_auth`: проверить, что ключи дошли.

## Как себя вести

Сначала ищи метод каталогом, не угадывай имя. Перед записью покажи человеку,
что именно уйдёт в API, и дождись согласия: гейт сработает всё равно, но
человек должен увидеть тело запроса до, а не после.

Числа из ответа не округляй и не пересчитывай в уме. Если метод вернул
пустой список, так и скажи, вместо того чтобы объяснять это за продавца.

Рекламный кабинет Ozon это отдельный API с другой авторизацией. Он тоже есть в `marketplaces-mcp-ru`, команда `ozon-perf-mcp`, 45 методов.

## Все четыре маркетплейса разом

Если нужны не только Ozon Seller, ставится комбайн `marketplaces-mcp-ru`:
Wildberries, Ozon, Яндекс Маркет и Авито в одном сервере.
